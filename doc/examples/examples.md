# Examples

End-to-end models that combine the pieces from the [User Guide](../user-guide/overview.md).
Each example is a Jupyter notebook. Use the download button at the top of a
page to run it locally.

<div class="grid cards" markdown>

-   :material-truck-delivery:{ .lg .middle } **[The Transport Problem](transport-tutorial.ipynb)**

    ---

    The classic GAMS transport tutorial, written in linopy, with the GAMS
    code alongside for comparison.

-   :material-transmission-tower:{ .lg .middle } **[Power Portfolio Build-Out](energy-resource-build.ipynb)**

    ---

    A capacity expansion model that selects and builds power generation
    resources to meet future demand.

-   :material-grid:{ .lg .middle } **[Sudoku Solver](sudoku.ipynb)**

    ---

    Indexing with N-D coordinates: a sudoku as a binary program.

</div>
